# Money-Tracker# 

## Overview of the project
This is a simple terminal program I made to help me track my pocket money and expenses[cite: 1]. It helps you see how much you earn, how much you spend, and if you are breaking your monthly budget[cite: 1]. 

## Features
* Set a monthly spending limit so you don't go broke[cite: 1].
* Add money you earned (income) from parents or part-time jobs[cite: 1].
* Record stuff you bought (expenses) like food or games[cite: 1].
* See a history list of all your money moves[cite: 1].
* See a dashboard with a cool text-based progress bar for your budget[cite: 1].
* Clear all data if you want to start over for a new month[cite: 1].

## Technologies/tools used
* Python 3[cite: 1]
* `datetime` module (comes with Python)[cite: 1]
* `time` module (comes with Python)[cite: 1]

## Steps to install & run the project
1. Download the `tracker.py` file to your computer[cite: 1].
2. Open your terminal or command prompt[cite: 1].
3. Make sure Python is installed[cite: 1].
4. Type `python tracker.py` and press enter to start the app[cite: 1].

## Instructions for testing
Just run the code and try typing letters when it asks for numbers to see the error handling work[cite: 1]. Try spending more than your budget to see the warning message pop up[cite: 1]!
